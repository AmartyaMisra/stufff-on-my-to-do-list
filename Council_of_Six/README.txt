================================================================
       COUNCIL OF SIX - USER GUIDE
================================================================

QUICK START (3 STEPS):

1. INSTALL PYTHON 3.10+
   Download: https://www.python.org/downloads/
   
2. RUN BUILD SCRIPT
   Windows: Double-click build_exe.bat
   Linux/Mac: Run ./setup.sh
   
3. START THE APP
   Windows: dist\Council_of_Six.exe
   Linux/Mac: python3 main.py

================================================================
WHAT IS THIS?

A desktop chatbot with six AI personalities who debate your
questions and vote on answers.

THE COUNCIL:
◆ Lalo Salamanca - Charming manipulator
◆ Robert California - Seductive philosopher  
◆ Patrick Bateman - Narcissist capitalist
◆ Alexander Mahone - Analytical profiler
◆ The Gorosei - Bureaucratic gods
◆ Hisoka Morrow - Jester-predator

================================================================
HOW TO USE:

1. Type your question in the input box
2. Press Enter or click Send
3. Wait 30-60 seconds for all 6 personas to respond
4. See vote tally (Agree/Disagree/Neutral)

FEATURES:
□ Online Mode - Enable web search
□ Debate Mode - Personas argue with each other
□ Export - Save conversation transcripts
□ Clear Chat - Reset conversation

================================================================
SYSTEM REQUIREMENTS:

✓ Windows 10/11, Linux, or Mac
✓ 8GB RAM minimum
✓ 5GB free disk space
✓ Internet (for model download only)

================================================================
TROUBLESHOOTING:

Problem: "Python not found"
Solution: Install Python and check "Add to PATH"

Problem: Slow responses
Solution: This is normal on CPU (1-3 tokens/sec)

Problem: Out of memory
Solution: Close other applications

Problem: Model download fails
Solution: Get HuggingFace token from:
         https://huggingface.co/settings/tokens
